# PolyScan Web

Site Next.js 14 pour présenter les produits PolyScan.

## Lancer le projet en local

1. Clone le dépôt :
   ```bash
   git clone <url-du-repo>
   cd ProjetPolyFinance
   ```

2. Assure-toi d'utiliser Node.js 18 (via nvm par exemple) :
   ```bash
   nvm install 18
   nvm use 18
   ```

3. Installe les dépendances :
   ```bash
   npm install
   ```

4. Démarre le serveur de développement :
   ```bash
   npm run dev
   ```

L’application est accessible sur `http://localhost:3000`.

Pour un build optimisé :
```bash
npm run build
npm run start
```
